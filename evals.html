How do you know it got better?: measuring agents, and improving them on purpose

A test either passes or it does not. An agent gives you a different answer every time, so “it works” stops being a thing you can assert and becomes a thing you have to measure. This lab is about that measurement, and about the disciplined loop that turns it into improvement: diagnose, change one thing, measure, keep it or throw it away. Eleven sections, plain English first, and simulations for the parts that only make sense once you have watched a number move the wrong way.

The machine behind this lab: a balance that needs more than one weighing

In plain English: you change a prompt and want to know if it got better. Here the old version and the new one sit on the two pans of a balance, and each run adds a weight as heavy as its score. After the first run the beam tips the wrong way. After five it settles. An agent gives a different answer each time, so the question is never “did it pass?” but “how often, and how badly, does it fail?”
